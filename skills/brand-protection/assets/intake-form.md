# 品牌维权资料表

可以复制下面内容填写，也可以直接用自然语言说明。已有资料只需给出文件/目录或附件，无需手工抄写证书。不确定的项目写“待定”；与当前任务无关的项目可以留空。填写后的版本保存在自己的案件目录，不放入通用 Skill 或共享仓库。

```text
品牌名称：
官方网站/官方店铺：
目标市场（国家/地区，或待定）：
资料位置（本地目录、附件或有权限的链接）：
疑似侵权链接/账号/商品（可多条，暂未发现可留空）：
希望达到的结果（如下架页面、停止收款、取回域名、准备海关材料）：
本次工作（整理资料 / 调查取证 / 起草材料 / 跟进既有投诉 / 按明确授权提交）：
```

以下信息仅在需要时补充；能够从资料读取的无需重复填写。

| 信息 | 填写内容 |
|---|---|
| 权利主体与关系 | 权利人/公司名称，你是权利人、员工或代理人；授权文件位置 |
| 产品或服务 | 涉及的产品/系列/服务，以及官方对照链接 |
| 权利材料 | 商标、版权、专利/外观设计、许可/转让等文件位置；没有也可说明 |
| 授权渠道 | 官方地区站、经销商、平台店铺、联盟推广等范围 |
| 已有证据 | 网页截图、原图、订单、物流、样品鉴定或消费者反馈的位置 |
| 已有案件 | 工单、历史投诉、决定、反通知和明确期限的原始材料 |
| 持续跟进 | 是否启用；反馈检查频率、时区、邮箱/工单入口及可读取的案件范围 |
| 催办范围 | 是否已授权同工单催办/补证；可发送内容、附件和接收方；需另行决定的升级事项 |
| 复发观察 | 是否在措施生效后继续观察，目标范围与频率 |
| 特殊要求 | 输出语言、优先级、预算、联系人、资料可披露范围 |

选择“提交”说明希望推进提交；最终对象、材料、声明、签名和费用仍以具体案件的已授权范围为准。输入资料的上传/读取权限不等于对外发送权限。

选择持续跟进后，可以采用每 6 小时查反馈、每天复查目标的运营起点；催办时限服从接收方规则及正式通知。已提供的持续跟进授权会保存在案件中，不必每轮重复填写。
