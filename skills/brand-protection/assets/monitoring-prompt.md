# 周期巡检提示模板

用于用户已要求启用的持续案件巡检。填完后通过当前环境正式自动化工具创建/更新；此模板本身不是已经运行的定时任务。先把用户已明确授权的范围写进私有案件记录，无需每轮重复征求同一授权。

```text
使用 $brand-protection，按其持续跟进规则处理以下已授权的私有案件索引：{{case_index_or_case_paths}}。

本次周期范围是 {{monitoring_scope}}，业务时区为 {{timezone}}。先读取最新授权、暂停范围、记录版本和未完成运行；按持续跟进规则取得真实独占，再领取本轮任务。租约过期只触发运行核查；有证据确认中断后才恢复只读任务，外发或结果不明的任务先核对送达，不能直接重试。

先检查与工单相关的已授权反馈源，再核对实际目标状态、补证/法定期限和待办。对照全部未结目标与已纳入渠道，补齐下一步、时间及具体阻塞；处理队列的 errors、held_tasks、recovery_tasks、coverage_gaps、deferred_tasks 和 deadline_conflicts，空队列不代表全部完成。已结原案关联的未结更正也要保留。

无反馈不等于发送失败。读取不完整不能推断没有回复。普通 SLA、法定期限与运营复查时间分别记录；不以普通催办冷却期延迟补证或更正，明确的全外发限制与期限冲突则保留并处理。发现原投诉有误时停止该主张的投诉与催办外发，按规则建立关联原行动的更正/撤回事项；单纯停工不等于获得对外撤回授权。按既定复发观察范围复查已采取措施的目标。

仅推进当前授权且符合渠道条件的动作；发送前必须先持久化 prepared，再持久化 in_flight 并核实成功，之后才调用发送工具。恢复时发现 prepared、in_flight 或 outcome_unknown，先核对，不能改键或另建行动绕过。未授权发送的项目形成可审阅草稿。

写回同一私有台账，保存原始回执、决定、下次行动、运行结果和修订号；消息引起的状态、期限、待办及已处理标记提交成功后才推进反馈游标。记录实际健康证据和独立观察者/人工接续的可用性；本轮执行不能证明自身失联时也能告警。对缺失权限或外部故障记录准确阻塞，并继续独立可做的工作。按规则通知实质变化，不把配置或试跑写成持续运行验收。
```

周期与运行状态由调度工具配置；通知偏好使用工具支持的设置与当前会话规则，不在提示中另藏冲突配置。不得把证书内容、个人资料、令牌或未知收件方填入提示。

## 独立健康观察提示（有实际能力和授权时）

此提示只用于已核实能在主执行环境失联时继续工作的观察者；不能因填了模板就登记 `independent`。来源、字段和状态遵循 [持续跟进规则](../references/follow-up.md) 的统一协议。没有该能力时登记人工接续或 `none`，不另建同机任务冒充独立监控。

```text
检查 {{authorized_scheduler_and_run_evidence}} 中已授权案件巡检的运行健康，按 {{expected_interval_and_grace}} 比对真实运行完成及成功写回证据。只检查所需运行元数据，不读取无关案件或邮箱，不代替主流程发送投诉、恢复任务或修改权限。

记录观察时间、最新可验证的成功运行、来源访问结果及健康结论。没有成功证据或主流程超出约定周期时，向 {{authorized_alert_destination}} 报告具体恢复条件；同一故障按既定通知策略处理，不能推断案件对方没有回复。更新台账时遵守同一独占与版本协议；无法取得独占时保留观察结果供任务持有者接续，不并发覆盖。
```
