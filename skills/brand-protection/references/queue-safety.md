# 队列安全契约与回归验收

本文件补充 [案件格式](case-format.md) 与 [持续跟进规则](follow-up.md)。队列仍只读，不提供发送器、排他锁、事务、法律期限计算或授权判断。`due_tasks` 不是发送许可。

## 外发候选的阻断

在生成任何候选之前，扫描全部任务和发送尝试，不依赖列表顺序。任一外发任务仍为 `in_progress`，即使运行已经结束、缺少发送记录、租约过期或该任务的到期时间损坏，也会阻断同一行动的新外发候选；先按恢复协议核清运行和送达，再保存实际结果。不能只换键、换轮次或移动任务位置。

`corrects_action_id` 连接的原行动、更正及后续更正共同承担未决发送/运行阻断；循环关联报错。关联只传播送达不确定性，不继承另一行动的授权、证据、冻结或终态。已关闭/冻结原行动没有未决发送时，合法独立更正仍可成为候选；无关行动及独立只读工作不会仅因该关联被拦截。

同一案件内，两个未关闭外发任务使用同一 `dedupe_key` 时，两者都保留并报告冲突，不任选一个。已记录的成功或未决发送继续按历史去重；已经核清并关闭的历史任务不禁止不同键的合法新周期。队列不据此宣称 exactly-once，实际发送仍需重新核验和独占保护。

## 字段与范围

`claim_frozen` 可省略；出现时必须为 `true` 或 `false`，`"true"`、`0`、`null` 等均需修复。可选时间限制允许省略或 `null`；其他值必须是带时区、可解析的时间字符串。不会把错误的假值当作没有限制，也不会猜测正确值。

行动必须关联本案有效目标。任务省略 `target_ids` 才继承行动范围；显式提供时必须非空、无重复、存在且属于行动。未知/隔离目标、显式空列表、越界目标均报错，不能扩成全案。只读的无行动任务仍可省略范围，用于已授权的案件级检查。

未结行动的覆盖按实际队列处置计算：到期/延期候选、已核验的进行中任务、或有有效原因和复核时间的显式阻塞任务才是下一步。被运行、冻结、去重或数据完整性拦住的 `planned/ready` 任务不再自动算作覆盖；恢复提示本身不是已经持久化的下一步安排。

## 期限关联

可选 `followup_tasks.deadline_ids` 显式指定本任务要响应的期限。非空列表中的 ID 必须存在且不属于其他行动；空列表表示不承担期限响应。没有该字段时保留旧记录的同一行动关联，但不将措施复核/复发观察自动当作当前应答任务。

该字段不创建、删除或完成期限。`deadline_alerts` 独立保留；配置错误或普通任务受阻也不能隐去有效期限。新案件应尽量记录明确关联，旧记录的兼容匹配仍须人工/代理核实，不能视作完整法律日历。

## 严格文件输入输出

案件以 UTF-8 读取并兼容 BOM。任何对象层级出现重复键都拒绝整份歧义文件；拒绝 NaN、Infinity 和浮点溢出。不能用最后一个键覆盖已有期限、授权或发送记录。无法解码、解析过深等输入按文件报错，其他文件继续计算。

报告使用 ASCII 转义 JSON（也是有效 UTF-8）；解析后中文值不变，在 ASCII 标准输出环境中也不会因中文导致报告丢失。退出码及错误报告必须同时检查。文件级拒绝不声称已提取该文件的期限，应恢复可信原件后重试。

## 测试与部署验收

在仓库根目录执行：

```bash
python3 -B -m unittest discover -s tests -v
```

原 `test_followup_queue.py` 保持不变。`test_audit_regressions.py` 保留审计的 16 项断言；`test_queue_hardening.py` 验证顺序、更正关联、严格类型、范围、期限和批次文件隔离；`test_queue_mutations.py` 在一个测试中执行 70 个位置 × 16 种值的 1,120 次变异，不把变异次数当成独立测试数量。

所有数据均为合成，测试不发信、不连接真实申诉渠道、不写回案件。CI 仅验证脚本契约，不证明 Agent 能抵御全部提示注入，也不证明真实邮箱、外发、落盘互斥、自然调度或独立健康观察已验收。部署应固定已审阅的 Git 提交；仍需在实际环境按持续跟进协议完成独立验收。
