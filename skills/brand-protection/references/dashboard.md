# 只读案件看板

本工具生成私有静态 HTML，展示指定案件的登记状态和队列结果。它不联网、不修改案件，不提供发送、审批或调度按钮。

## 使用方法

先创建仓库外的私有输出目录，再运行：

```bash
python3 scripts/case_dashboard.py \
  --case /path/to/private-case/case-record.json \
  --output-root /path/to/private-reports
```

多案重复传入 `--case`。每次生成独立的 `dashboard-` 目录，页面为 `index.html`，不会覆盖旧报告。页面可以在本地浏览器中打开。Windows 还需核对输出目录的访问权限。

默认每类明细最多展示 200 行。可用 `--row-limit` 调整，范围为 1 至 1,000。超过上限时显示截断提示，统计仍保留已读取的全部记录。

## 如何读取结果

行动阶段来自台账。草稿、已提交、已受理、机构报告采取措施和台账记录复核生效分别统计。看板不把这些阶段合并成成功数量，也不重新验证真实处理结果。

到期、阻塞、延期、恢复、覆盖缺口和期限冲突直接来自现有只读队列。看板不复制一套队列判断。队列检查失败时显示未知和错误位置，不能视为零待办。

未完成期限独立展示。即使没有启用周期跟进，台账中的期限也不会被隐藏。未知或无效时间标为待核实；工具不计算工作日或猜测正式截止时间。

原行动关闭后，尚未结束的更正仍单独计数。重复案件 ID 分开显示并提示，不合并成一个案件。同类重复记录按原有校验规则隔离，错误位置继续保留。

## 隐私与显示安全

页面只投影运行所需的 ID、阶段、时间和诊断信息，不复制证书、材料正文、接收方或完整案件。原始错误详情不嵌入页面，需要回到台账和队列输出核对。

所有动态内容经过 HTML 转义。页面没有脚本、表单、外链或外部资源，并设置内容安全策略。控制字符会被移除，过长文字会截断。实现参考 [Python HTML 转义文档](https://docs.python.org/3/library/html.html)和 [CSP 说明](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy)。

**页面仍是私有报告，不能默认公开。** 案件及记录 ID 本身可能含敏感信息。不要把报告托管到公共网站或作为投诉附件直接发送。

## 刷新与退出码

页面记录生成时点，不自动刷新。新的反馈或案件变化需要重新运行。页面显示不代表调度器仍在线，也不证明任务已经执行。

退出码 `0` 表示报告生成且未发现记录错误；`1` 表示输入或校验存在问题，或写入失败。部分输入错误时，仍生成可读取案件的报告并标出失败项。检查标准输出中的实际保存路径。
