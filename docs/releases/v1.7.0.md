# v1.7.0 只读案件看板

本版增加私有静态案件看板。看板共用原台账和队列，不创建平行状态库。

## 更新内容

新增 `scripts/case_dashboard.py` 和使用说明。页面分别显示行动阶段、未完成期限、阻塞、恢复、覆盖缺口和未结更正。未启用跟进时仍展示已记录的期限；队列失败时显示未知，避免误报零待办。

页面没有发送按钮、表单、脚本或外部资源。动态内容转义后显示，私有材料正文和接收方不进入页面。报告按次保存，不覆盖既有文件。

新增 19 项投影与输出测试，以及 3 项真实队列集成测试。完整测试继续在源码与解压安装包中执行。

## 安装与限制

安装方法见附件 `INSTALL.md`。看板只展示生成时点的台账，不验证真实投诉结果，不自动刷新，也不提供后台健康保证。

案件和记录 ID 仍可能包含敏感信息。报告须保存在私有目录，分享前另行审查。
