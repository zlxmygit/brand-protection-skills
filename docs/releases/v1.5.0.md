# v1.5.0 提交前审查

本版增加只读提交前审查。工具把审批绑定到当前正文、附件、接收方、目标、权利材料、费用和授权范围。

## 更新内容

新增 `scripts/submission_review.py`、空白审批模板和使用说明。没有审批时可计算待审快照；有审批时重新读取文件并核对哈希。材料、反证或授权变化后，旧审批不再匹配。

已有审批不能解除冻结、终态、未决发送、同键已发或渠道时间限制。原行动已结束时，独立更正仍可审查；原通知送达不明时，更正保持阻塞。

新增 25 项测试，覆盖材料变化、审批时效、跨案和跨品牌引用、未决送达、更正关联、反证及授权变更。分发的审批模板全部留空或设为 `false`。

## 安装与限制

安装方法见附件 `INSTALL.md`。已有案件不自动迁移。待审材料放入行动的可选 `preflight_payload`，不改写历史提交。

工具不认证审批人、不判断侵权、不发送材料。检查通过后，仍需核对最新反馈、队列、当前授权和实际发送字节。
