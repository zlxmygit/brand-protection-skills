# v1.1.0 调查结果标准化

本版增加调查结果格式和只读校验器。安装与升级方法见附件 `INSTALL.md`。

## 更新内容

调查记录区分注册信息、品牌关系、行为线索和来源覆盖。查询失败、未查到和没有行为线索分别处理。品牌自有资产出现异常时，工具要求复核该资产。

新增 `scripts/investigation.py`、调查说明和辅助工具索引。原有跟进队列保持不变。新增测试覆盖旧案件兼容、重复 ID、来源失效、范围错误、证据引用和中文输出。

本版同时补齐发布校验：固定提交、文件白名单、安装包解压测试、逐文件哈希和远端下载复验。只有校验通过才公开正式 Release。

## 兼容与权限

案件格式保持 `1.3`。调查扩展使用独立的 `investigation.version: 1.0`。旧案件没有该字段时，工具返回 `no_records`，不要求迁移。

本版不查询网络、不写回案件、不发送投诉，也不启动监测。退出码 `0` 仅表示记录通过结构检查。

## 文档维护

仓库在 `.agents/skills/zh-tech-writing/` 安装中文技术写作 Skill，并保留原许可和来源。该目录仅供开发文档使用，不进入品牌维权安装包。
