# v1.8.3 原生跨平台支持

本版补齐 macOS、Windows 和 Linux 的运行、安装及发布验证。不增加投诉渠道、数据源或自动外发权限。

## 兼容修正

原版在新增的两种 Mac 原生运行器上出现目录校验错误。macOS 的系统 `/var` 别名使临时证据、导出和审查目录被统一拒绝。本版仅兼容 root 所有、指向准确目标的 `/var` 和 `/tmp` 别名，继续拒绝用户创建的符号链接。

Windows 路径检查覆盖目录联接及其他重解析点，拒绝设备路径、UNC、备用数据流、保留名称和歧义盘符相对路径。文件写入显式使用二进制模式。中文和空格路径、BOM、CRLF 以及原生 PowerShell 命令均纳入测试。

安装包仍为同一个通用 ZIP。脚本使用 Python 标准库，不要求 WSL、Docker 或管理员权限。推荐 Python 3.13；旧版 Python 3.9 只保留兼容测试。

## 原生验证矩阵

CI 必须通过以下八个任务后才发布：Ubuntu 22.04 的 Python 3.9、3.11、3.13、3.14，以及 Ubuntu 24.04、Windows Server 2025、macOS 15 arm64 和 macOS 15 Intel 的 Python 3.13。

五个 Python 3.13 平台任务分别构建、解压到含中文和空格的目录、运行安装包完整测试，并检查公开 `example.com` RDAP 与 HTTPS 采集。Windows 原生测试不由 WSL 替代。未在矩阵中的系统版本和架构不宣称已实机验收。

本版保留原有 357 项测试，新增 26 项路径、字节和命令测试，以及 8 项构建编码和测试计数检查。平台专属用例在相应系统执行，在其他系统明确跳过；跳过不计作通过。`VALIDATION.json` 增加运行环境及发现、通过、跳过数量。

## 安装与权限

下载本版 ZIP 和配套校验附件，按 `INSTALL.md` 中的 macOS / Linux 或 Windows 步骤安装。包内 `references/platform-support.md` 说明原生命令、私有目录、ACL 和迁移限制。升级前把旧目录备份到宿主扫描路径之外，避免混装。

案件格式与审批格式不变，本版不改写私有案件。Windows 的 `0600` 不等于私有 NTFS ACL；应先核对保存目录的权限和继承。路径兼容不代表可将真实资料放入安装目录、共享盘或公开仓库。

通用包不含真实品牌、案件、证书、订单、凭据或私有日志。维护用 `zh-tech-writing` 不进入独立包。脚本、安装包和公开接口测试不代替实际宿主、反馈、签署、外发或调度验收。
