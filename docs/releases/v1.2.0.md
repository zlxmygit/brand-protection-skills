# v1.2.0 单域名注册查询

本版增加一个可选的只读数据源：Verisign RDAP。只查询用户明确指定的 `.com`、`.net` 域名，复用 v1.1.0 的调查结果格式。

## 更新内容

新增 `scripts/rdap_lookup.py` 和使用说明。工具固定查询主机，拒绝重定向，不读取代理配置，不上传案件材料。成功结果保留查询时间和响应哈希；查询失败与未查到分别处理。

新增 13 项测试，覆盖注册结果、404、限流、错误响应、超时、体积限制及调查格式兼容。发布前另用解压安装包查询公开测试域名，失败时停止发布。

## 安装与兼容

安装方法见附件 `INSTALL.md`。新增工具需要 `--allow-network` 才会查询。已有案件和队列保持不变，无需迁移。

工具不判断侵权，不猜测品牌关系，不自动写回案件。完整响应正文不会自动归档。高频扫描、更多后缀和其他数据源不在本版范围内。
