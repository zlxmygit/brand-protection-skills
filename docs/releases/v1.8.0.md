# v1.8.0 消费者沟通草稿

本版只增加消费者沟通材料。工具使用同一案件中的官方渠道，生成入口说明、客服线索核对话术和线索提交说明。

## 更新内容

新增 `scripts/consumer_materials.py`、三份通用中文模板、空白复核模板和使用说明。工具检查品牌、渠道来源、证据引用、核验时效和客服入口，不把其他案件的资料作为默认值。

草稿与来源、模板及实际文本形成同一快照。渠道或文本变化后，旧复核不再匹配。模板提醒最小披露，不索取密码或完整卡号，不承诺退款或下架，不认定未列出的第三方违法。

新增 22 项合成测试，覆盖跨案引用、未核实入口、过期依据、文本变化、隐私字段排除、复核匹配和失败清理。此前各轮测试和公开接口检查继续保留。

## 安装与限制

安装方法见附件 `INSTALL.md`。案件使用可选的 `consumer_communications`，无需自动迁移。

本版只生成中文纯文本草稿，不联网、不发送、不公开发布。所有输出保留草稿标识。记录通过检查不认证身份、网站归属或实际发布权限。

## 迭代范围

本版完成本轮计划的第八项能力。已交付调查格式、一个 RDAP 数据源、一种 HTTPS 取证方式、证据导出、提交前审查、一个 Cloudflare 渠道配置、只读看板和消费者沟通草稿。

这些能力共用原台账和主入口。更多数据源、渠道、浏览器取证和真实发送仍需独立开发与验收，不因本轮完成而默认具备。
