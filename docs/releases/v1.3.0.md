# v1.3.0 受控网页取证

本版增加一种取证方式：保存公开 HTTPS 页面响应。输出包括原始字节、访问地址、跳转记录、采集时间、部分响应头和哈希。

## 更新内容

新增 `scripts/capture_web.py` 和使用说明。工具要求显式网络权限和主机范围，拒绝内网地址，固定连接到已检查的 IP。TLS 仍核验原始主机名。

默认不跟随跳转，不运行 JavaScript，不使用登录会话。响应保存为私有目录中的 `.bin` 文件。写入失败会清理本次目录，既有证据保持不变。

新增 18 项测试，覆盖访问范围、地址检查、跳转、证据哈希、私有路径、截断响应和 TLS 校验。发布前用解压后的脚本访问公开示例页面，并核对保存字节。

## 安装与限制

安装方法见附件 `INSTALL.md`。案件格式和原有队列保持不变。新脚本只写入显式指定的私有证据目录，不改写案件台账。

本版不提供浏览器截图、可信时间戳或公证。HTTP 状态只表示本次访问结果；403、404 和超时不能证明处理成功。默认披露级别为受限，导出前仍须审查。
