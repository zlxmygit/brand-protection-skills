# v1.6.0 Cloudflare 版权渠道配置

本版只增加一个渠道配置及只读检查器。它区分反向代理与实际托管角色，不把商标或仅有售假指称转换成版权报告。

## 更新内容

新增 `scripts/channel_check.py`、结构化配置和使用说明。检查器要求角色归属证据、当前政策与表单审查，以及逐项作品和页面对应。

代理报告只允许请求转交，托管报告可以请求审查指定内容。工具不签署声明、不提交报告，也不计算法定期限。渠道审查记录变化后，旧材料审批不再匹配。

新增 19 项合成测试，覆盖角色能力、来源有效期、跨品牌证据、页面范围、表单确认及审批快照关联。现有测试与公开查询验收保持不变。

## 安装与限制

安装方法见附件 `INSTALL.md`。行动使用可选 `channel_review`，旧案件不自动迁移。

官方说明已核验，真实表单未提交。实际提交前仍须检查当期表单、材料、权限和反馈。其他渠道后续分别配置。
