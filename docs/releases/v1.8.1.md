# v1.8.1 审计安全修复

本版修复 v1.8.0 审计发现的 A01 至 A06，不增加自动外发能力。推荐使用本版替换 v1.8.0；已有私有案件保持原件，按下述要求补齐实际记录。

## 修复内容

| 问题 | 本版处理 |
|---|---|
| A01 审批依赖不完整 | 解析权利材料、授权、正反证、观察、归属及派生父链，读取真实文件并绑定哈希。缺失依赖不生成可批准的快照。 |
| A02 跨品牌冲突 | 调查、导出和渠道检查统一核对显式案件、品牌及目标标签，并检查父链。 |
| A03 首次通知衔接 | 队列支持 `initial_notice`，保留未决发送、去重和运行阻断。 |
| A04 服务商目标错配 | 单目标需要明确归属，多目标需要逐项证据。不能用另一个站点的服务商记录通过检查。 |
| A05 源码包输出隔离 | 无 `.git` 的源码目录及宿主扫描目录也受到保护，私有输出仍放在外部。 |
| A06 RDAP 消息完整性 | 拒绝短读、歧义长度、冲突编码和不完整分块，失败结果保持未知。 |

更正关系校验改为线性遍历，另加长链、环和工作量上限测试。构建输出 `dist/` 加入忽略列表。

## 安装与兼容

下载本版 `brand-protection-v1.8.1.zip` 和 `SHA256SUMS.txt`，按附件 `INSTALL.md` 核对并安装。先将旧 Skill 目录备份到宿主扫描路径之外，再复制完整新目录。不要混合新旧脚本，也不要覆盖私有案件。

案件格式保持 `1.3`。提交前快照改为 `1.1`，旧审批需要重新复核；不能自动更新哈希来冒充新批准。单目标渠道归属须补充实际核实的 `target_id`。多目标逐项归属及可选权利范围说明见包内 `references/audit-fixes.md`。

本版的文档写作 Skill 仍只用于仓库维护，不进入独立安装包。

## 验证与权限

保留原有测试断言，渠道成功夹具只补充新增必填的目标事实。审计反例纳入正式测试；新增失败场景和长链检查。源码、解压包、公开 `example.com` 示例及上传后的下载文件分别验收，具体结果由发布流程附在本页及 `VALIDATION.json`。

测试使用合成数据。通用包不包含真实品牌资料、案件、证书、订单、凭据或私有日志。没有发送投诉、签名、付款、公开消费者材料或启用业务监测。检查通过仍不是提交许可。
