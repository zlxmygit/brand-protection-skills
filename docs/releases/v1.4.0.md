# v1.4.0 证据包导出

本版只增加证据导出和逐项披露检查。工具复用同一案件的证据记录，不创建平行台账。

## 更新内容

新增 `scripts/evidence_export.py` 和使用说明。工具按审查清单读取文件，核对案件、哈希、派生关系、接收方和批准有效期。原件默认排除，确需导出时须逐项明确批准。

输出采用独立私有目录。ZIP 只含选中的字节和最小清单；内部授权引用、本机路径和接收方留在私有回执。写入失败不改变原件。

新增 21 项合成测试，覆盖选择范围、过期批准、文件变化、跨案引用、目录越界、循环引用、大小限制、失败清理及采集后导出。

## 安装与限制

安装方法见附件 `INSTALL.md`。案件格式保持 `1.3`，披露审查文件独立保存。

本版不联网、不自动脱敏、不发送投诉。真实披露审查仍由有权限的人完成，填写状态字段不能代替该工作。
